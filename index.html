    None of these is reserved, and the two numbers above are not in tension. var.immut.i64 ['loop'] declares a variable called 'loop'; a function may be called 'a name with spaces' or '🔥'. A name wears marks and a bare word never does, so no word ever has to be taken away from you to make room for the language. It is the same list quench words prints.

    —

      Twenty-two of the twenty-eight kinds of token are symbols, each one its own spelling. The other six are described rather than spelled, because they have no fixed spelling to give: a name is whatever stands between marks, a written value whatever stands between the other pair, and a word is any bare word at all. The split is the compiler’s own — it is how each kind names itself in an error message.
