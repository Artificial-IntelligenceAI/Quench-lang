About

Quench is a language built around three things: explicit syntax, okay performance, and very helpful error messages.

It is under development, and nothing in it is stable. Stability is not a guarantee.

Compile once, run anywhere

A program compiles to one artefact — serialised QIR — and that artefact runs on whatever machine it lands on. The machine decides how. Because it travels, QIR is not allowed to know what machine it is for: no pointer width, no calling convention, nothing target-specific anywhere in it.

Four ways, and they must agree

Two of the four run today.

InterpreterBeing believed. It generates no code and lowers nothing, so when the engines disagree it is the one that is right.Working

Agreement is a test, not a hope

A generator writes programs that are guaranteed to compile, and every one of them is run by every way at every optimisation level. The answers must match — including how a program stops, since stopping in the same place for the same reason is as much an agreement as printing the same number.

Where it stands: 200,000 programs, 600,000 comparisons, 28 seconds on ten cores. That rate used to be four times quicker, and got slower on purpose: a generated program used to be arithmetic and loops, and now it allocates arrays, reads exact rationals and decimals, joins text and prints — and every one of those is compared.

Any disagreement is a bug in at least one engine, and the seed that produced it is kept so it can be replayed.
